# Солнечные ладони — демонстрация сайта

Концепция сайта детского центра для презентации компании. Дизайн, фотографии и тексты перенесены из предоставленного экспорта Claude.

## Файлы

- `index.html` — страница, оформление и тексты.
- `app.js` — открытие формы, выбор занятия и проверка полей.
- `assets/` — изображения и шрифты.

Страница работает без сборки. Форма демонстрационная: данные не отправляются и не сохраняются. Для реального приёма заявок нужен отдельный обработчик.

## Публикация

GitHub Pages публикует изменения основной ветки `main` через GitHub Actions. В настройках репозитория **Settings → Pages → Source** нужно выбрать **GitHub Actions**. Адрес сайта появится в разделе Pages и в результате выполнения Publish website.

Лицензии шрифтов сохранены в комментарии в начале `index.html`. Права на контент остаются у соответствующих правообладателей.
